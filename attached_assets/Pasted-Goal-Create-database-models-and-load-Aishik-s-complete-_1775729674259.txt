## 1. MODELS/DATABASE.PY

Create these SQLAlchemy models:

### JobPosting Model (for deduplication)
- id: Integer, primary key
- job_hash: String(100), unique, indexed (for dedup)
- company_normalized: String(200)
- role_normalized: String(200)
- location: String(100)
- first_seen_url: String(500)
- first_seen_platform: String(50)
- first_seen_date: DateTime
- duplicate_urls: Text (JSON array)
- times_seen: Integer, default 1

### Application Model (main tracker)
- id: Integer, primary key
- job_posting_id: ForeignKey to JobPosting
- company: String(200), required
- role: String(200), required
- location: String(200)
- url: String(500)
- platform: String(50)
- score: Float (0-5)
- grade: String(1) (A/B/C/D/F)
- archetype: String(50)
- recommendation: String(20)
- visa_sponsorship: String(20) (yes/no/unclear)
- evaluation_json: Text
- jd_text: Text
- status: String(50), default 'Evaluated'
- cv_generated: Boolean, default False
- cover_generated: Boolean, default False
- applied_date: DateTime
- created_at: DateTime, auto
- notes: Text

### ScanHistory Model
- id: Integer, primary key
- url: String(500), unique
- platform: String(50)
- scanned_at: DateTime
- result: String(20) (new/duplicate/skipped)
